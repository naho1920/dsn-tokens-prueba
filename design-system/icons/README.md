# Íconos

Generado por DS Crack. Cada ícono está dos veces:

- `svg/`: el SVG suelto, para cualquier stack.
- `react/`: un componente React por ícono.

Los dos usan `currentColor`: el ícono toma el color del texto que lo rodea.

```tsx
import { ChevronDownIcon } from "./icons/react";

<ChevronDownIcon />                               // decorativo, 24 px
<ChevronDownIcon size="var(--icon-size-md)" />  // tamaño desde un token
<ChevronDownIcon title="Abrir menú" />          // con nombre para lectores de pantalla
```
